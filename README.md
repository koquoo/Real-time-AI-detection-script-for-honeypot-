#  AI-Based Real-Time Honeypot Detection System

##  Overview
This project is a real-time honeypot monitoring system that uses machine learning, specifically **Isolation Forest**, to detect anomalous and potentially malicious activity. It analyzes system or network logs and flags unusual behavior in real time.

---

##  Features
- Real-time anomaly detection  
- ML-based threat identification using Isolation Forest  
- Data preprocessing and log cleaning  
- Detection of suspicious patterns in system activity  
- Lightweight Python implementation  

---

##  Technologies Used
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Isolation Forest (Unsupervised Anomaly Detection)  

---

##  How It Works
1. Collects or simulates log/system activity data  
2. Cleans and preprocesses input data  
3. Applies **Isolation Forest model** to detect anomalies  
4. Flags abnormal or suspicious behavior  
5. Outputs results for monitoring and analysis
